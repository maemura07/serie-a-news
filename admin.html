表記辞書エディタ

選手・監督・クラブのカタカナ表記を統一する辞書（names.json）をブラウザから編集します。左に「ブレた表記」、右に「正しい表記」。保存すると次の自動更新から反映されます。

🔑 初回設定：アクセストークン

保存にはGitHubのアクセストークン（このリポジトリ専用の合鍵）が必要です。作り方：GitHub右上のアイコン → Settings → 一番下の Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。設定は3つだけ：①Repository access で「Only select repositories」→ serie-a-news を選択 ②Permissions → Repository permissions → Contents を「Read and write」に ③Expiration はお好みで（切れたら再発行）。できた github_pat_... を下に貼って保存。このトークンはこの端末のブラウザにだけ保存され、他人には見えません。

表記辞書エディタ

直近の記事に登場した名前が下に並びます。表記が間違っているものだけ「直す」を押して正しい表記を入力 → 最後に画面下の「保存する」。← サイトに戻る

🔑 初回設定：アクセストークン

保存にはGitHubのアクセストークン（このリポジトリ専用の合鍵）が必要です。作り方：GitHub右上のアイコン → Settings → 一番下の Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。設定は3つ：①Repository access で「Only select repositories」→ serie-a-news ②Permissions →「＋ Add permissions」→ Contents を追加して「Read and write」に ③Expiration はお好みで。できた github_pat_... を貼って保存。トークンはこの端末のブラウザにだけ保存されます。

🔄 今すぐ更新

通常は2時間おきの自動更新ですが、このボタンで即座にニュース収集を実行できます（完了まで1〜3分）。

👀 直近の記事に出てきた名前（登場回数順）

おかしい表記だけ「直す」。すでに辞書に載っているものにはラベルが付きます。人名以外（用語など）が混ざっていたら無視してOK。
